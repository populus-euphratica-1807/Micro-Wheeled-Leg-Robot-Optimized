基于 Mu Shibo 开源轮足机器人项目的深度重构与系统性优化版。本项目在保留原硬件方案的基础上，对软件架构、数据链路、调参方法和性能评价体系进行了全面升级。

核心优化工作：

1.软件架构升级：引入 FreeRTOS 双核任务调度，将平衡控制任务（Core 0，1kHz）与通信任务（Core 1）完全解耦，杜绝控制周期受网络阻塞干扰的问题

2.实时数据链路：新增 UDP 20 维状态数据实时采集功能，每 20ms 向 PC 端发送包含角度、角速度、控制量、电池电压等完整状态快照，支持 Python 端自动接收并写入 CSV

3.在线调参系统：重构网页控制端，集成 PID 在线调参面板，支持 9 个 PID 控制器及 3 个低通滤波器的实时参数修改与一键回读，无需重新编译固件

4.量化评价体系：设计 ITAE（时间加权绝对误差积分）作为核心性能指标，结合超调量惩罚与稳态误差惩罚，将"站稳"从主观感受转化为可复现的量化得分

5.贝叶斯自动寻优：基于 bayesian-optimization 框架，实现 PID 参数的闭环自整定——优化器推荐参数→WebSocket 下发小车→UDP 采集数据→计算 ITAE 得分→更新概率模型→迭代逼近全局最优解

## [v2.1] - 2026-06-14

### Added
- 百分制评价函数，返回 0-100 得分及详细指标（ITAE、超调角度、振荡次数、力矩抖动）
- 实验稳定性检查功能 `prepare_robot()`，自动等待机器人扶正并稳定 3 秒以上
- 动态最佳安全参数回退机制，当机器人不稳时自动下发已知最优安全参数
- 参数渐变切换（先到中间值，1.5秒后再到目标值），减少冲击
- 基线测试功能，用安全参数进行首轮测试并注册进优化器
- 优化过程可视化：自动绘制得分、ITAE、超调、振荡、力矩抖动曲线并保存 PNG
- 实验数据自动记录到 CSV 文件 (`optimization_log.csv`)

### Changed
- 优化方向改为直接最大化百分制得分（旧版本为最小化负得分）
- 摔倒/失败检测升级：连续 10 帧同时超角度 45° 且超角速度 100°/s 才判定摔倒
- 搜索空间根据实物特性收窄至更合理范围
- 稳定等待时间从 3 秒延长至 5 秒，确保参数完全生效
- UDP 采集器增加 `latest_record` 和 `last_records` 属性，支持实时状态查询
- 所有打印增加 `flush=True`，确保日志实时输出

### Fixed
- 修复旧版本因 UDP 数据突变导致的频繁误判失败问题
- 修复 WebSocket 响应阻塞可能导致程序无响应的问题（添加超时处理）
- 修复程序异常退出时资源未正确释放的问题

### Improved
- 整体异常捕获和资源清理，程序鲁棒性大幅提升
- 评价函数增加静止数据检测，排除机器人未启动的无效测试
- 代码可读性和模块化进一步优化
