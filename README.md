基于 Mu Shibo 开源轮足机器人项目的深度重构与系统性优化版。本项目在保留原硬件方案的基础上，对软件架构、数据链路、调参方法和性能评价体系进行了全面升级。

核心优化工作：

1.软件架构升级：引入 FreeRTOS 双核任务调度，将平衡控制任务（Core 0，1kHz）与通信任务（Core 1）完全解耦，杜绝控制周期受网络阻塞干扰的问题

2.实时数据链路：新增 UDP 20 维状态数据实时采集功能，每 20ms 向 PC 端发送包含角度、角速度、控制量、电池电压等完整状态快照，支持 Python 端自动接收并写入 CSV

3.在线调参系统：重构网页控制端，集成 PID 在线调参面板，支持 9 个 PID 控制器及 3 个低通滤波器的实时参数修改与一键回读，无需重新编译固件

4.量化评价体系：设计 ITAE（时间加权绝对误差积分）作为核心性能指标，结合超调量惩罚与稳态误差惩罚，将"站稳"从主观感受转化为可复现的量化得分

5.贝叶斯自动寻优：基于 bayesian-optimization 框架，实现 PID 参数的闭环自整定——优化器推荐参数→WebSocket 下发小车→UDP 采集数据→计算 ITAE 得分→更新概率模型→迭代逼近全局最优解

相比初版（v1.0-initial）的主要修复：

热修改积分参数时自动调用 targetPid->reset()，清除旧积分累积值，避免参数切换瞬间的数值抖动

迭代历程： 本仓库保留三个分支——original（原作者代码）、v1.0-initial（初版重构，存在已知问题）、main（最终修复版），完整记录从原始开源项目到系统优化的全过程。
