基于 Mu Shibo 开源轮足机器人项目的深度重构与系统性优化版。
原项目地址：
https://github.com/MuShibo/Micro-Wheeled_leg-Robot

本项目在保留原硬件方案的基础上，对软件架构、数据链路、调参方法和性能评价体系进行了全面升级。

核心优化工作：

1.FreeRTOS 双核架构：平衡控制任务绑定 Core0，通信 / Web 任务绑定 Core1，彻底避免网络阻塞干扰控制周期，平衡频率更稳定。

2.UDP 实时状态广播：以 50Hz 频率输出全量机器人状态（角度、角速度、控制量、电压、零点等 18 项数据），支持上位机无损采集。

3.现代化 Web 控制端：重构 UI 为卡片式响应式布局，新增 PID 在线调参面板、参数一键读取、实时串口日志回显，无需接串口即可调试。

4.Python 自动调参工具链：基于贝叶斯优化的 PID 参数自动整定，内置 ITAE、超调、振荡次数、稳态误差、力矩抖动多维度评价函数。

5.软件脉冲扰动测试：通过程序偏移平衡零点模拟外力冲击，量化测试控制器的恢复性能，无需手动拨动机器人。

6.分段评价体系：将响应过程拆分为「恢复段」与「稳态段」分别加权评分，评价维度更贴合平衡机器人实际使用需求。

7.实验自动化管理：自动保存每组参数的阶跃响应曲线、CSV 原始数据、优化趋势图、基线对比图，结果可追溯。

8.多层安全机制：电池欠压停机、倒地自动关停、参数渐变切换、连续失败自动终止优化，最大限度保护硬件。

收紧 PID 参数搜索空间边界，规避易失稳区域，显著提升优化效率

重构 Python 上位机为面向对象结构，统一日志与目录管理，代码可维护性更强

优化 UDP 采集逻辑：采集前清空队列，确保数据时间起点对齐
